New SuperR7-specific code and substantial SuperR7 modifications are marked
with `Copyright (C) 2026 Danny Nunez (dnunezx)` in their source headers. Future
commits in this repository should use Danny Nunez (dnunezx) as the author name

## Upstream foundation

SuperR7 is based on [SuperFW](https://github.com/davidgfnet/superfw), primarily
written by **David Guillen Fandos (`davidgf`)**. Original copyright headers,
GPL licensing, technical identifiers required for compatibility, and upstream
attribution are deliberately retained.

The initial SuperR7 history also preserves upstream commits so authorship can
be traced at the line and commit level. The upstream repository should remain
configured as a read-only remote for selectively reviewed fixes.

## Third-party components

The inherited project also uses third-party components including nanoprintf,
heapsort, FatFs, apultra/upkr, and linker/startup work adapted from AntonioND.
Their original notices and licenses remain authoritative.
